# Teisti

## Description

Universal food delivery website API.
Presents list of categorized food products to order.

## Functionality

- Filter/Search products by Name, Category, Price
- Basket
- User account
- Owner account to add/modify/delete products
- Admin account to add/delete users

## Development/Learning steps

1. C# Basics.
2. ASP.NET Basics. Asynchronous programming with Task Parallel Library.
3. Project setup:
    - Dependency Injection.
    - Multiple projects per solution.
    - HTTP File.
4. Clean Architecture + CQRS.
5. EF Core: In-Memory Database.
6. Unit Testing: MSTest + NSubstitute.
7. Integration Testing: MSTest.
   WebApplicationFactory + In-Memory Database for testing.
8. PostgreSQL:
    - Docker Container.
    - Entity configuration.
    - Database migration.
    - Dotnet user-secrets.
9. Docker Compose.
10. Replace In-Memory Database with PostgreSQL on Testcontainers for API tests.
